# Cloud Application

## Этап развития
Фильтрация и контроль состояния облачных сервисов.

## Требования
* **REQ-01**: Ограничить допустимые значения поля status фиксированным набором состояний (например, running, stopped, error).
* **REQ-02**: Реализовать логику фильтрации списка сервисов по статусу в сервисном слое.
* **REQ-03**: Добавить параметр запроса status в эндпоинт получения списка сервисов для фильтрации выдачи.
* **REQ-04**: Обеспечить валидацию передаваемых параметров фильтрации на уровне API.
* **REQ-05**: Реализовать возможность поиска облачных сервисов по подстроке в их названии через параметры запроса.
